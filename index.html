architecture

Preinstalled jab

Written from scratch in Rust. Syncs recipes directly from GitHub, resolves dependencies, and tracks clean file manifests.

dinit & jabinit

Ships with fast dinit service supervision by default, with optional drop-in support for custom Rust PID 1 (jabinit).

Bring Your Kernel

No bloated distro kernels. Compile vanilla or custom Linux kernels tailored strictly to your own hardware.

jab quickstart

$ sudo jab i busybox
Resolve dependencies, build from source, and install a package
$ sudo jab u -f
Sync GitHub recipe tree and perform a full system rebuild
$ sudo jab r -p busybox
Remove an installed program cleanly via its manifest
