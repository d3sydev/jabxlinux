Writing Custom Package Recipes

Need software that is not yet in the official Jabx repository? Because jab builds directly from plaintext recipes, adding your own local package takes less than 30 seconds.

1. Local Repository Directory

Create a directory for your package inside /var/db/jab/local/<package-name>/ and place a single file named package inside it. Local recipes automatically take priority over upstream repository recipes. 

sudo mkdir -p /var/db/jab/local/mytool
sudo hx /var/db/jab/local/mytool/package

2. Example: Compiling a Rust Project

Use the $PKG_DIR environment variable as your installation root. jab tracks every file placed inside $PKG_DIR to generate a clean removal manifest. 

name=d3clock
version=0.1.0
url=https://github.com/d3sydev/d3clock.git
depends=rust
build=cargo build --release && install -Dm755 target/release/d3clock "$PKG_DIR/usr/bin/d3clock"

3. Example: Compiling a C / Makefile Tarball

name=htop
version=3.3.0
url=https://github.com/htop-dev/htop/releases/download/3.3.0/htop-3.3.0.tar.xz
sha256=a69acf9b42ff592c4861010fce7d1006805f4d6ef0e8705be222238826efe6ea
depends=ncurses
build=./configure --prefix=/usr && make -j$(nproc) && make DESTDIR="$PKG_DIR" install

4. Build & Install Your Custom Package

sudo jab i d3clock
jab l
